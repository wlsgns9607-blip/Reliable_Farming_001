# 우리밭 식구 (Our Farm Family)

**대한민국 농민을 위한 지능형 농업 비서 서비스**

'우리밭 식구'는 대한민국의 기후와 토양, 그리고 농민의 생활 패턴을 깊이 이해하여 농사일에 실질적인 도움을 드리는 농업 전문 지원 애플리케이션입니다. 특히 고령 농민 사용자를 배려한 직관적인 디자인과 안전 기능을 최우선으로 설계되었습니다.

## 🌟 주요 기능

1.  **AI 척척박사 작물 추천**: 대한민국의 계절과 기후에 맞춘 제철 농산물(마늘, 양파, 고추 등) 재배법과 관리법을 전문가처럼 안내합니다.
2.  **어르신 맞춤형 UI**: 큰 글씨, 고대비 색상, 직관적인 아이콘을 사용하여 누구나 쉽게 조작할 수 있습니다.
3.  **안전 SOS 시스템**: 위급 상황 시 즉시 주변에 도움을 요청할 수 있는 강력한 경고음 발생 기능을 탑재했습니다.
4.  **스마트 날씨 정보**: 농작물 관리에 필수적인 지역별 정밀 날씨와 작물 관리 팁을 실시간으로 제공합니다.
5.  **친절한 안내 가이드**: 모든 기능에는 '이 박사'의 음성 설명 버튼(스피커 아이콘)이 있어 사용법을 말로 들려드립니다.

## 🛠 기술 스택 및 구현 방식

본 애플리케이션은 현대적인 웹 기술을 사용하여 빠르고 안정적으로 작동합니다.

*   **Frontend**: `React 18`과 `Vite`를 기반으로 한 단일 페이지 애플리케이션(SPA) 구조.
*   **Styling**: `Tailwind CSS`를 사용하여 고대비 및 반응형 디자인을 세밀하게 구현했습니다.
*   **Animations**: `motion/react`를 활용해 부드럽고 직관적인 화면 전환과 상호작용 피드백을 제공합니다.
*   **Icons**: `lucide-react`를 사용하여 농업 테마에 맞는 명확한 시각적 지표를 구현했습니다.
*   **Architecture**: Gemini API 연동 및 보안을 위해 `Express` 서버가 Vite 미들웨어와 결합된 Full-stack 구조를 채택했습니다.

## 🎨 디자인 철학

*   **가독성**: Inter 및 굵은 서체를 활용하여 정보가 한눈에 들어오도록 설계했습니다.
*   **친숙함**: 연한 녹색(#C8E6C9)과 브랜드 컬러인 딥 그린(#2E7D32)을 사용하여 농촌의 편안함을 표현했습니다.
*   **조작성**: 모든 터치 대상을 크게 설계하여 실내외 어디서든 오동작 없이 사용할 수 있습니다.

## 🚀 구글 안티그래비티 (AI Studio Build)로 수정하는 방법

이 애플리케이션은 **Google AI Studio Build** 환경에서 개발되었습니다. 복잡한 코드를 직접 수정하는 대신, 아래와 같이 자연어로 명령하여 앱을 쉽게 바꿀 수 있습니다.

### 📝 수정 방법 (Step-by-Step)
1.  **채팅창 열기**: 화면 하단의 채팅창(Antigravity Agent)을 확인합니다.
2.  **명령어 입력**: 원하는 변화를 사람에게 말하듯 입력하세요.
    *   *예시: "홈 화면의 글씨를 좀 더 크게 키워줘"*
    *   *예시: "농사일지 작성할 때 사진도 여러 장 올릴 수 있게 해줘"*
    *   *예시: "배경색을 좀 더 밝은 연두색으로 바꿔줘"*
3.  **결과 확인**: 명령을 입력하면 AI가 코드를 자동으로 수정하고 배포합니다. 잠시 후 새로고침된 화면에서 결과를 확인하세요.

### 💡 팁
*   구체적으로 말할수록 정확하게 수정됩니다. (어느 화면의 어느 버튼인지 등)
*   디자인 수정뿐만 아니라 새로운 기능을 추가하는 것도 가능합니다.
*   수정 내용이 마음에 들지 않으면 "방금 친 거 취소하고 이전으로 되돌려줘"라고 말하면 됩니다.

## 🚀 네이버 로그인 연결 예정

현재 네이버 로그인은 API 연동 준비 중이며, 해당 버튼 클릭 시 임시 계정으로 로그인되도록 처리되어 있습니다. 추후 정식 API가 연결될 예정입니다.

## 🚀 버셀(Vercel) 배포 가이드

본 앱을 Vercel에 배포할 때 원활한 동작을 위해 다음 설정을 확인하세요:

1.  **환경 변수(Environment Variables) 설정**:
    *   `GEMINI_API_KEY`: Google AI SDK를 위한 API 키.
    *   `NAVER_CLIENT_ID`: 네이버 개발자 센터에서 발급받은 클라이언트 ID.
    *   `NAVER_CLIENT_SECRET`: 네이버 개발자 센터에서 발급받은 클라이언트 시크릿.
    *   `APP_URL`: 애플리케이션의 기본 URL (예: `https://our-farm.run.app`). 네이버 로그인 콜백 URL 생성에 사용됩니다.

2.  **네이버 로그인 콜백 등록**:
    *   네이버 개발자 센터 내 애플리케이션 설정에서 **Callback URL**을 다음과 같이 등록하세요:
    *   `{APP_URL}/api/auth/naver/callback` (예: `https://our-farm.run.app/api/auth/naver/callback`)

3.  **빌드 및 실행**:
    *   **Build**: `npm run build`
    *   **Start**: `npm start`
    *   현재 구조는 Full-stack으로, Express 위에서 Vite가 번들된 정적 파일을 서빙하며 API 요청을 처리합니다.
