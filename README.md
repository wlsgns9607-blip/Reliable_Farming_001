# 우리밭 식구 (Our Farm Family) 🌾

**대한민국 고령층 농민을 위한 포용적 웹 접근성 기반의 지능형 농업 UI 지원 서비스**

'우리밭 식구'는 대한민국의 기후와 토양, 그리고 고령 농민의 현장 패턴을 깊이 이해하여 농사일에 실질적인 도움을 드리는 농업 지원 웹 애플리케이션입니다. 특히 디지털 소외 계층인 시니어 사용자를 배려하여 KWCAG(한국웹콘텐츠접근성지침) 기준의 **고대비 레이아웃**, **초대형 터치 영역(48px+)**, **음성 인식 연동(Voice-First UI)**을 최우선으로 마크업 및 구축했습니다.

---

## 🌟 주요 UI/UX 기능 및 코딩 스펙 (Core Features)

1. **AI 척척박사 작물 추천 UI**: 대한민국의 계절과 기후에 맞춘 제철 농산물(마늘, 양파, 고추 등) 재배법과 관리법을 AI API 데이터 바인딩을 통해 직관적 카드로 출력합니다.
2. **시니어 특화 접근성 UI**: 큰 글씨, 고대비 색상, 직관적인 시각 요소(lucide-react)를 적용하여 실외 햇빛 아래서도 눈 피로 없이 조작 가능하도록 스타일링했습니다.
3. **안전 SOS 시스템 인터랙션**: 위급 상황 시 한 번의 터치로 강력한 경고음과 알림 패널이 즉시 트리거되는 비상 UI를 탑재했습니다.
4. **스마트 기상 데이터 대시보드**: 농작물 관리에 필수적인 지역별 정밀 날씨 API 연동 및 작물 관리 팁 컴포넌트를 반응형 레이아웃으로 전면 배치했습니다.
5. **Web Speech API & 음성 안내 가이드**: 모든 기능에 '이 박사'의 음성 설명 버튼(스피커 아이콘)을 마크업하여, 텍스트를 직접 읽지 않고 말로 들을 수 있는 Voice-First 인터페이스를 완성했습니다.

## 🛠 Tech Stack & Architecture (기술 스펙)

본 애플리케이션은 현대적인 웹 기술을 사용하여 빠르고 정교하게 작동합니다.

* **Frontend**: `React 18` 및 `Vite` 기반의 단일 페이지 애플리케이션(SPA) 반응형 구조
* **Styling**: `Tailwind CSS` 기반의 시니어 특화 CSS Variables 및 고대비 레이아웃 구현
* **Animations**: `framer-motion`을 활용해 인지 피로를 최소화하는 정갈한 인터랙션 제공
* **Icons**: `lucide-react`를 이용한 명확하고 고대비화된 시각 지표 마크업
* **Architecture**: Gemini API 연동 및 보안 처리를 위해 `Express` 서버와 Vite 미들웨어가 결합된 Full-stack 서비스 구조

## 🎨 UI/UX 구축 철학 (Design & Publishing Principles)

* **가독성 극대화**: 굵은 서체 및 KWCAG 명암비 가이드라인을 준수하여 정보에 즉시 도달하도록 설계했습니다.
* **친숙한 컬러 시스템**: 연한 녹색(#C8E6C9)과 브랜드 컬러 딥 그린(#2E7D32)을 매칭하여 시인성을 높이고 시각적 편안함을 선사합니다.
* **터치 타겟 최적화**: 모든 터치 대상을 48x48px 이상으로 확대 설계하여 야외 농가 환경 및 장년층 오동작을 원천 차단했습니다.

### 📝 AI 기반 빠른 UI 수정 workflow
1. **프롬프팅 입력**: AI 통제 채팅창(Antigravity Agent)을 통해 UI 수정 및 컴포넌트 확장 지시
   * *예시: "홈 화면의 폰트 크기를 KWCAG 시니어 접근성 기준에 맞춰 최상위 단계로 키워줘"*

2. **코드 즉시 추출 및 배포**: AI가 마크업 및 스타일링 코드를 실시간으로 재구축하고 라이브 배포 환경으로 자동 동기화.

## 🚀 Vercel / Cloud Run 배포 가이드

본 앱을 배포 플랫폼에 적용할 때 원활한 API 데이터 바인딩을 위해 다음 설정을 적용합니다.

### 1. 환경 변수 (Environment Variables) 설정
* `GEMINI_API_KEY`: Google AI SDK 연동을 위한 API 키
* `NAVER_CLIENT_ID`: 네이버 개발자 센터 클라이언트 ID
* `NAVER_CLIENT_SECRET`: 네이버 개발자 센터 클라이언트 시크릿
* `APP_URL`: 애플리케이션 기본 도메인 URL (예: `https://our-farm.run.app`)

### 2. 네이버 로그인 Callback URL 설정
네이버 개발자 센터 내 애플리케이션 설정에서 **Callback URL** 등록:
`{APP_URL}/api/auth/naver/callback`

### 3. 빌드 및 실행
* **Build**: `npm run build`
* **Start**: `npm start`
* Express 위에서 Vite가 번들된 정적 파일을 서빙하며 API 연동을 처리하는 구조입니다.
